# E2E 验收

1. admin 登录，在设置页创建普通账号；普通账号可登录。
2. 普通账号拥有看板、列表、每周筛选、概览、设置、记录、导入和导出；无账号管理入口，直调管理接口返回 403。
3. admin 与普通账号互相看不到对方想法；导出只包含自己的数据。
4. 修改密码后退出，新密码可重新登录且保留本人数据。
5. 同浏览器多标签页切换账号后，旧标签页重新获取当前身份，移除旧管理员入口；退出和改密同步退出其他标签页。
6. 原有 17 项桌面/移动端完整业务回归继续通过。

用例：`e2e/accounts.spec.ts`、`e2e/account-tabs.spec.ts`、`e2e/funnel.spec.ts`。产物位置：`.playwright/账号体系-20261031/results/`。
