# 集成审查

- 已核对登录、当前用户、改密、管理员列表/创建的参数、返回字段、错误码和页面引用。
- 所有业务路由从会话取得 owner；管理员无跨账号读取特权。账号列表游标基于唯一用户名，使用索引，分页测试覆盖 102 条。
- 新迁移保留 admin 内部 id=me，建立归属外键。真实旧库升级测试验证想法、标签、事件均保留；无管理员占位的负控制触发外键失败。
- 会话仅存令牌摘要；密码版本和行锁阻止旧凭据在改密后创建有效会话；初始化配置不会覆盖已修改密码。
- 审查发现并修复：改密原密码猜测缺少限流；多标签页切换账号残留旧缓存；旧想法 UUID 删除并由其他账号重新导入后的标签/事件写入竞态。均增加先失败后通过的测试。
- 事件列表在同一 SQL 快照内完成归属校验与读取；标签与评分/阶段事件子写分别校验 owner，父 UPDATE 的行锁保护事务内数据。
- 平台入口不再使用 SESSION_SECRET；README、环境变量示例和 CLAUDE.md 已同步。前端未增加运行时 shared/schema 导入或新依赖。
- E2E 使用独立新建 PGlite 目录，显式清空远端数据库环境变量；不删除既有测试数据库，不连接共享库。
