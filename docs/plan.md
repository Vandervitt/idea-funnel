| # | 任务 | 验证方式 |

## 需要你配合的事项（只在 M3 部署时需要）

1. 确定部署平台，并登录对应的 CLI（`npx wrangler login` 或 `vercel login`）。
2. 准备一个 Neon 数据库，拿到 `DATABASE_URL`。
3. 运行 `npm run hash-password` 生成密码哈希，明文密码不会经过我。
4. 在远端数据库执行迁移、首次部署：这些操作会写入你的云账号，执行前我会先征得你同意。
